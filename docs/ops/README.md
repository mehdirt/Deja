# Ops docs

Runbooks for release, store submission, and incident handling. Add a file per runbook as each process is first executed for real.

- `community-runbook.md` — how reports arrive, how to triage them, how to review a pull request, and the one-time GitHub setup the flow depends on (private vulnerability reporting, Discussions, labels). Read this before announcing the repo anywhere.
- `release-runbook.md` — publishing the extension to the Chrome Web Store, hosting the landing page, and the soft-launch plan.
